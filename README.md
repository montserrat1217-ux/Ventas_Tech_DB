# RetailPro - Proyecto de Análisis de Datos

## Descripción

RetailPro es un proyecto de análisis de datos orientado al estudio del comportamiento comercial y de ventas.

El objetivo del proyecto es analizar el comportamiento de las ventas de RetailPro, identificar productos y clientes relevantes y construir un modelo de información que facilite la toma de decisiones comerciales.

## Objetivos

- Crear y estructurar una base de datos de ventas.
- Analizar facturación, productos y clientes.
- Aplicar consultas SQL con JOIN y UNION.
- Construir un proceso ETL.
- Crear un modelo de datos en Power BI.
- Desarrollar indicadores mediante DAX.

## Herramientas utilizadas

- SQL Server
- SQL Server Management Studio (SSMS)
- Power BI Desktop
- GitHub

## Orden recomendado del proyecto

1. M3 - Creación de la base de datos y carga de información.
2. M4 - Consultas de análisis de ventas.
3. M5 - Consultas con JOIN y UNION.
4. M6 - Limpieza y transformación de datos en Power BI.
5. M8 - Modelo de datos, tabla calendario y medidas DAX.

## Análisis realizados

Las consultas desarrolladas permiten analizar:

- Facturación mensual.
- Ticket promedio.
- Ranking de productos.
- Clientes recurrentes.
- Comparación de ventas.
- Productos y clientes con o sin registros asociados mediante JOIN.
- Integración de información mediante UNION.

## Contenido del proyecto

El repositorio contiene los distintos ejercicios y entregas desarrollados durante el proyecto RetailPro:

- Creación y carga de la base de datos.
- Consultas SQL de análisis comercial.
- Consultas con JOIN y UNION.
- Transformación y limpieza de datos.
- Modelo de datos en Power BI.
- Medidas DAX para análisis de ventas.

## Ejecución de los scripts SQL

1. Instalar SQL Server y SQL Server Management Studio.
2. Abrir SQL Server Management Studio.
3. Conectarse a una instancia de SQL Server.
4. Ejecutar primero los scripts correspondientes a la creación de la base de datos y las tablas.
5. Ejecutar los scripts de carga de datos.
6. Ejecutar posteriormente las consultas de análisis.
7. Revisar los resultados obtenidos antes de continuar con los módulos posteriores.
